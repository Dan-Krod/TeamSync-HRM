# Архітектура Бази Даних (ER-діаграма)

База даних системи **StaffFlow HRM** спроектована з урахуванням модульності та збереження цілісності реляційних зв'язків. Схема містить 8 таблиць, які покривають усі ключові бізнес-процеси управління персоналом.

## 🗄 Структура та зв'язки

* **Ядро системи:** Таблиця `employees` є центральною. Вона має подвійний зв'язок із `departments` (належність до відділу та управління ним) і виступає головним ключем для більшості інших сутностей.
* **Кадрові процеси:** Таблиці `leave_requests`, `attendance_records` та `payrolls` пов'язані з `employees` відношенням "один-до-багатьох" (один працівник може мати багато записів).
* **Оцінка продуктивності:** Таблиця `performance_reviews` містить два зовнішні ключі, що посилаються на `employees` (ідентифікація працівника та його керівника-рев'юера).
* **Ізольовані модулі:** Таблиця `candidates` відповідає за рекрутинг і є повністю ізольованою, оскільки кандидати не є частиною внутрішньої структури компанії до моменту найму.
